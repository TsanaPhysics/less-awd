# less-awd

### ระบบตรวจวัดระดับน้ำและคาร์บอนเครดิตภาคเกษตร (LEQs-AWD Smart Rice Node)
**นวัตกรรมเกษตรอัจฉริยะแม่แบบเปิด พัฒนาต่อยอดจากพิมพ์เขียว HandySense (เนคเทค สวทช.)**  
หน่วยวิจัยคุณภาพสิ่งแวดล้อมท้องถิ่น (LEQs) คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี จ.จันทบุรี

---

## 📌 ภาพรวมโครงการ (Project Overview)
**LEQs-AWD** (หรือ Less-AWD: Alternate Wetting and Drying) คือนวัตกรรมระบบตรวจวัดระดับน้ำใต้ผิวดินในแปลงนาข้าวแบบเปียกสลับแห้งอัตโนมัติ เพื่อส่งเสริมการทำนาลดโลกร้อนและลดการปล่อยก๊าซมีเทน ($CH_4$) ได้เฉลี่ย 48% พร้อมทั้งประหยัดน้ำชลประทานได้ 30–50% และรองรับการบันทึกข้อมูลเพื่อขอรับรองคาร์บอนเครดิตภาคสมัครใจตามมาตรฐานของประเทศไทย (T-VER)

---

## 🌾 คุณสมบัติเด่นของระบบ (Core Features)
1. **การวัดระดับน้ำแม่นยำสูง (Precision Water Telemetry):**
   - วัดระดับน้ำในท่อสังเกตการณ์เจาะรูใต้ผิวดินลึก 20–25 ซม. ด้วยเซนเซอร์อัลตราโซนิกกันน้ำระดับ IP67 (AJ-SR04M)
   - เกณฑ์แจ้งเตือนน้ำแห้งที่ปลอดภัย (-15 ซม. จากผิวดิน) ไม่ทำให้ผลผลิตข้าวลดลง
2. **หน้าจอแสดงผลข้อมูลภาคสนาม (On-Field Display):**
   - จอ LCD 20x4 I2C / 3.5" TFT Smart Display มองเห็นค่าน้ำ แบตเตอรี่ และสถานะวาล์วผ่านกล่องกันน้ำ IP65 ฝาใส
   - ระบบประหยัดพลังงานพักหน้าจออัตโนมัติ (Auto-Sleep 30s)
3. **การสื่อสารสองระบบ (Dual-Architecture):**
   - **Local Direct Mode:** เชื่อมต่อตรงกับสมาร์ทโฟนผ่าน Bluetooth LE / WiFi AP หน้าแปลง โดยไม่ต้องเสียค่าบริการ Cloud Server (ต้นทุน 0 บาท)
   - **IoT Cloud Mode:** ส่งข้อมูลผ่านเครือข่าย 4G LTE CAT-1 เข้าสู่ Cloud Broker และระบบประมวลผล T-VER
4. **ระบบพลังงานแสงอาทิตย์อิสระ 100%:**
   - แผงโซลาร์เซลล์ 20W + โซลาร์ชาร์จเจอร์ PWM 10A + แบตเตอรี่ลิเธียมฟอสเฟต LiFePO4 12.8V 6Ah สำรองไฟได้นานกว่า 4–5 วันต่อเนื่อง
5. **น้อง iLEQs AI Assistant:**
   - ผู้ช่วยอัจฉริยะประจำระบบ ให้คำแนะนำการจัดการน้ำ การคำนวณคาร์บอนเครดิต และการบำรุงรักษาระบบ

## 💰 การประเมินงบประมาณอุปกรณ์ฮาร์ดแวร์ (BOM Summary)
* **งบประมาณชิ้นส่วนฮาร์ดแวร์จริงทั้งชุด (15 รายการหลัก):** **3,030 – 5,010 บาท** *(ค่าเฉลี่ยมาตรฐาน ~3,630 บาท)*
* **ประหยัดกว่าชุดเชิงพาณิชย์ในท้องตลาด (7,500 – 10,000 บาท):** **49.9% – 59.6%**
* **ระยะเวลาคืนทุน (ROI Payback):** คืนทุนภายใน **1 – 2 ฤดูกาลทำนา** จากค่าน้ำมันสูบน้ำ ค่าปุ๋ย และรายได้คาร์บอนเครดิต
* *(หมายเหตุ: เป็นราคาประเมินเฉพาะชิ้นส่วนฮาร์ดแวร์ ไม่รวมค่า Cloud Server, ฐานข้อมูล และการพัฒนาแอปพลิเคชัน)*
